This is a two concept project
1. The idea of utilizing a rigid system
2. That is must be in motion — and that that motion must somehow be re-translatable to static mediums

What do they need to make for the project.
    - Identity
        * pick whatever you want, if you are already doing an identity project for another class, and would like to expand upon it for this project be my guest
    
    Okay, so here is the deal. You are coming up with a kit of parts and then a "system" for their use. However, this is open to interpretation. Perhaps your kit of parts is a pattern and a set of guidelines for its use...
    
    ALSO motion. 
    Your logo has to be in motion, there must be an animation that either
        1. creates visuals/patterns for use in your static material that then results in a final logo @ the end
            (the animation "builds" the logo, and then the resulting frames of the animation are usable elsewhere to create varied, but thematically similar, "branded" pieces. — the box one from behance)
        2. There are set rules for your logo and various inputs change the visual output based on these rules — the northern norway one does this. There are then a semi-infinity number of "logos" that you have use of now. This however requires additional work to output (think of the Current TV one too, this is a "rule" based logo, but you still have to design and create all additional brand materials and graphics, it doesn't generate itself )
        3. There must be more... The Walker one? that is just a set of rules, there actually isn't a logo, the "look" is the logo, not any one thing in and of itself...
        4. More???
