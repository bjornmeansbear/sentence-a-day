## The core idea behind the archive

The work seems to be about how design can be understood as a way of thinking about the world: not just as decoration or visual output, but as a practice tied to ecology, ethics, technology, and culture.

## Useful ways to work with these themes moving forward

1. Create a small set of hub tiddlers for major themes
   - Sustainability and Systems
   - Design as Practice
   - Open Source and Commons
   - Ethics and Politics
   - Writing and Reflection
   - Materials and Circularity
   - Typography and Visual Language

2. Add cross-links from existing tiddlers to those hubs
   - This will make the archive feel more connected and easier to browse.

3. Use consistent tags
   - Suggested tag groups: sustainability, design, systems, climate, open-source, commons, typography, philosophy, ethics, politics, writing, journal, notes, materials, circularity, visual-culture.

4. Make the archive easier to navigate by theme
   - A “theme map” could become a landing page for exploration.
   - Each hub could list representative tiddlers and related questions.

5. Treat the archive as a thinking system, not only as a publication archive
   - The strongest tiddlers often connect ideas across disciplines.
   - Future work could focus on surfacing those connections more deliberately.

## Good next steps

- Turn the existing theme map into a richer set of linked hub tiddlers.

- Review the tag set and normalize recurring terms.
- Build one or two “entry points” for new readers, such as:
